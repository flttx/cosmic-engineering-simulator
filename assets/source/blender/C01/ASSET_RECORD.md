# C01 采能卫星制作记录

Tripo 任务 `80e211fb-e27e-42d3-9314-21f2c314455c` 消耗 50 credits，输入生成结果为 `assets/source/tripo/tripo-out/c01-collector-master-80e211fb/model.glb`。源 GLB 57,093,296 bytes，含 11 个网格和 1,977,565 个源三角面。实际以 metadata 的 `sourceFaces` 为准。

通过 Blender 5.2.1 LTS 的原生 GLTF 导入、Decimate、Merge by Distance、Recalculate Normals、Smart UV 与 GLTF 导出加工。脚本 `scripts/blender_c01.py` 可在项目根复现。主工程 `collector_master.blend` 包含隐藏的 `TRIPO_ORIGINAL_UNMODIFIED` 原始集合，以及可编辑的 `C01_EDITABLE_REPAIRED` 集合；原始集合不参与运行时导出。

首次浏览器美术审查指出原生成端部的团块熔化、原翼的皱折和叠层遮挡为 P1 缺陷，因此拒绝这些形体进入运行时。完整原件仍保留；只保留经裁切、减面、焊接与法线修复的中央 Tripo 内部设备区域。围绕候选结构在 Blender 局部重建明确的笼架、斜撑、检修顶板、机加工圆柱端舱、环箍、对接面和螺栓、姿态喷口。替换原皱折翼为有厚度的成对采能翼、电池分格、独立散热翼和有连接的铜质热管。提高金属材质粗糙度，消除液态般强高光。所有新增形体在源工程内独立可编辑；没有声称该设计是已完成工程验证的硬件。

glTF 坐标为 +Y 向上、采能面朝 +Y；尺寸是教学显示单位，不提供虚构的米数、质量、效率或真实航天器比例。用户要求增强巨物感后，维护艇固定缩为初版 1/6，最大跨度约 0.1833 显示单位，采能翼跨度约为其 36 倍；不随相机改变比例。小艇增加玻璃窗、窗框、检修舱口和低亮导航标记，源形体保留在 `MAINTENANCE_EDITABLE_FIXED_CONCEPT_SCALE` 集合。不能据此推导真实尺寸。

质感修订将采能面设为非金属硅片玻璃层压材质，陶瓷散热器为非金属，高金属度用于真实金属构件。保留九张 512×512 PNG 主贴图，分别覆盖硅片子电池与互连线、钛合金加工纹和隔热毯拼缝的 Base Color / Roughness / Normal。采用明确的每面 UV 平铺而非独占涂装 atlas；重复贴图属于材料设计，不存在烘焙重叠写入问题。运行时图片直接嵌入 GLB。补充舱口铰链、微型紧固件、翼框紧固件、夹紧线缆束和检修踏面，圆柱端舱按角度平滑法线，避免近距明显棱面。

三种 LOD 共用父节点、原点、朝向、材质和部件层级。仅运行时副本按逻辑部件与材质合并到 12 个网格、5 种材质，源工程不合并细件。最终面数、文件体积以 `public/assets/C01/asset_metadata.json` 的 `lods` 为准。所有网格导出 UV 与法线。运行 `node scripts/asset_check.mjs` 验证 GLB、层级、各 LOD 减面、源工程和 metadata，并验证贴图嵌入及硅片/陶瓷非金属参数。

新版输出整体透视、采能正面、底部结构、前后两侧、四部件隔离及两张材质近图，共十一张 studio PNG。主卫星不使用 Bloom 或发光材质。原端部熔化和源翼皱折已经移除；中央内部设备仍保留少量生成雕刻纹理，外侧明确承力构件和检修板覆盖其主要轮廓。浏览器中的实际光照反射、拾取、隔离、爆炸、恢复及尺度感仍需独立复审，不能仅凭导出通过宣称最终验收完成。
